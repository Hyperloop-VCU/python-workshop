# HyperLabs introductory programming workshop - Code and Content Repository
Hello and welcome to the HyperLabs introductory programming workshop! In this GitHub code repository, you'll find all the supplementary content we'll use in the workshop. This includes setup/installation guides, cheatsheets, code, and project instructions.

We organize the content into "Parts". Each part is structured as follows:
* Conceptual explanations / slides (presented in person)
* Basic practice: writing simple programs
* Debugging practice: fixing errors in small existing code snippets
* And most importantly... cool projects. Most part folders have *unfinished games* in them, and once we cover the basics, you'll get to modify these projects or add new features to the games using the knowledge you just learned.
